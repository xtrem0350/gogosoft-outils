# Audit des Hero Banners

## Constat technique

- Le composant partagé `src/components/PageHero.tsx` utilise par défaut une image Unsplash demandée en largeur 1200 px. Il est appelé à 37 endroits : 36 utilisent cette image par défaut et le dashboard super-admin fournit une URL différente.
- Les bannières `PageHero` n’ont pas de ratio fixe : hauteur minimale de 160 px (176 px à partir du breakpoint `sm`), augmentant selon le contenu. La largeur dépend du conteneur. Les prompts visent une source 16:9 affichée avec `object-cover`.
- Les pages d’accueil, de configuration et d’authentification utilisent la même image Unsplash en fond plein écran.
- La vitrine publique peut afficher une bannière téléversée par chaque boutique ; cette image personnalisée ne doit pas être remplacée globalement.
- Le bandeau du dashboard standard et celui de la fenêtre « Nouveautés » sont des dégradés CSS, pas des images.
